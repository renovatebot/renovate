Versioning for [Go modules](https://go.dev/ref/mod#versions).

It behaves like the `semver` versioning for now, and is not yet the default for the `go` datasource or the `gomod` manager.
Go-specific behaviour, such as for [pseudo-versions](https://go.dev/ref/mod#pseudo-versions) like `v0.0.0-20191109021931-daa7c04131f5`, will be added over time.
